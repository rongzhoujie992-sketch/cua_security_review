# Release

Version `0.5.2` (2026-08-18) contains 226 studies, 501 Candidate Operations, 282 qualified HPATs, 4550 candidate-audit decisions, 2538 HPAT relation decisions, and 1927 evidence artifacts. It corrects the S-050 guarded forwarding transition: pre-effect denial is retained as operation-constraint evidence but is no longer coded as post-effect Containment. Corpus populations and the coding contract are unchanged.

Version `0.5.1` (2026-08-17) contains 226 studies, 501 Candidate Operations, 282 qualified HPATs, 4550 candidate-audit decisions, 2538 HPAT relation decisions, and 1927 evidence artifacts. It includes non-exclusive contribution-role annotations for 91 HPAT-positive studies and the released independent-coder comparison and adjudication records. This version corrects three source-grounded relation-status records without changing corpus populations or the coding contract.
