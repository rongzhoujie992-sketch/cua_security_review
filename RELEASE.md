# Release Notes

## v1.0.0 (2026-08-17)

This release combines two previously validated public components:

- PRISMA reproducibility release `1.0`;
- HPAC/HPAT v3.1.2 coding artifact `0.5.0`.

The integration adds a deterministic corpus crosswalk and a top-level validation command. It does not alter either child component, its data, its codebook, or its child manifest.

The main review denominator remains 222 studies. The 12 foundational sources, 4 TDES academic sources, and 5 official deployment documents are reported as supplementary evidence routes. The coding denominator is 226 records because it includes the four selected TDES academic sources; it excludes foundational and official deployment documents.

The package is ready for repository publication. It does not include reviewed-paper PDFs, credentials, private communications, private working directories, or exploit payloads.
