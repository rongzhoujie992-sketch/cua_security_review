# Release 2.0.0

This release contains the PRISMA reproducibility materials and the HPAC/HPAT
v3.3.0 coding data for the CUA security review.

- Main systematic corpus: 222 studies
- Coding population: 226 studies
- Candidate records: 1,031
- Qualified HPATs: 246
- Relation records: 2,214
- Evidence artifacts: 1,606

Reviewed-paper full texts are not redistributed. Run `python
scripts/validate_release.py` from the repository root to verify the release.
