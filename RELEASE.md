# Release

**Version:** v1.0.2
**Release date:** 2026-08-18

This release contains the PRISMA reproducibility materials, HPAC/HPAT coding data, source crosswalk, validation scripts, and file manifests for the CUA security review.

The release contains a 222-study systematic corpus, 12 foundational sources, 4 supplementary academic sources, 5 official deployment documents, and a 226-study HPAT coding population. It does not redistribute reviewed-paper PDFs, credentials, private communications, private working directories, or exploit payloads.

Run python scripts/validate_release.py from the repository root to validate the released package.
